### 2. New standing rule: negative findings need two probes (CLAUDE.md)
Adopted on PO direction after THREE false premises came out of Wave 0, each caught only by
re-probing: "PRAGMA foreign_keys is off" (false), "there is no router.delete in trips.ts"
(false — and the COO propagated it unchecked), "the firewall reaches no Turso host" (false,
found this session). Shared shape: probe once, get a negative, report the absence as fact.

Rule: a claim that something does not exist / is not enabled / is unreachable needs TWO
independent probes that could fail differently, or an explicit UNVERIFIED marker naming the
probe and its blind spot. Binds agents AND the COO propagating agent findings.

Placement was checked, not assumed: neither .claude/agents/*.md nor any role system prompt
references CLAUDE.md, so canonical text lives in CLAUDE.md and a pointer went into all 8
role system prompts (which each agent definition already calls the source of truth).
