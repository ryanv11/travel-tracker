### 3. Three guardrails adopted, all hook-backed (PR #310)
- **OP-28 — no wholesale rewrites of shared records.** Trigger: B1 and B2 ran concurrently
  and BOTH rewrote `jobs/frontend/context/current.txt` in full; each silently dropped the
  other's record and it surfaced only as a merge conflict. RECURRENCE — Wave 0 saw the same
  file collide in 3 of 4 agents and the fix identified then was never adopted.
  PO wanted a blanket "never fully rewrite anything" and invited calibration. Adopted split:
  shared records (`jobs/**`, tracker.json, BRD, ADL log, `.planning/**`, CLAUDE.md) are
  append/amend-only — Edit not Write; source-code rewrites stay allowed but must be DECLARED
  in the completion report. New `.claude/hooks/no-wholesale-rewrite.sh`, warn-only, 6 tests.
  **Root cause also fixed:** all 8 role prompts said "Update context/current.txt with current
  state" — that instruction was itself producing the rewrites. Now "APPEND a new dated entry".
- **OP-29 — negative findings bind every role, COO included.** Two fixes: the written rule
  now says no role is exempt and that a claim inherited from an existing project doc is NOT
  pre-verified (age is not evidence); and the OP-26 hook's COO-shaped hole is closed. It
  matched only `Write|Edit`, but the COO doesn't write briefs to files — it writes them into
  GitHub issue bodies via Bash, so the highest-leverage place for a false absence was the one
  place the hook couldn't see. Now also scans `gh issue create`/`gh pr create` bodies.
  **Pattern set widened, found by testing not assumption:** the original regex missed BOTH
  phrasings that actually caused this project's false premises — "is not enforced" and
  "there is no X". Both now covered and regression-tested.
- **OP-30 — scanner suppressions need COO sign-off.** B2 hit a genuine Gitleaks false
  positive on text it had just written and resolved it by adding `.gitleaks.toml`. The config
  is KEPT (useDefault=true, exact-string allowlist, not a path/file exemption). The precedent
  was governed instead: reword your own text first; never add or widen a suppression without
  sign-off; pre-existing annotated `nosemgrep`s unaffected.
