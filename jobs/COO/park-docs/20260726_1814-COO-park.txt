### 1. Production deploys were blocked (OP-23 / ADL-40) — the session's real find
Ryan reported he could not deploy production. Diagnosed: `Security Checks` failed on
production@299ab5c on GHSA-v422-hmwv-36x6 (body-parser, HIGH), and Railway gates prod
deploys on GitHub CI green.

The promotion did not cause it. `npm audit` queries the GitHub Advisory Database at RUN
TIME, so its verdict is a function of commit AND date. Proven, not assumed: the identical
commit 299ab5c passed on main 2026-07-24 and failed on production 2026-07-26, and
`git diff 299ab5c 3889436 -- package-lock.json package.json` is empty (only drift-ledger,
STATUS.md, tracker.json and a park doc changed between them).

Railway's own deployment history confirmed the blocker was real and not cosmetic: two
SKIPPED deploys on 299ab5c (its CI gate declining), then SUCCESS once promoted forward.

Fix (Ryan's call, and the better one — Railway is all-or-nothing about which checks gate,
so splitting the audit into its own workflow would not have helped): security.yml's push
trigger `branches: ["**"]` -> `branches-ignore: ["production"]`. ci.yml deliberately
unchanged and still gates prod.

Why this does not weaken security, and the insight worth keeping: GitHub check runs attach
to a COMMIT SHA, not a branch, and production is only ever fast-forwarded from main. Every
promoted SHA therefore already carries this workflow's green statuses earned on main.
Skipping the re-run does not remove the verdict — it FREEZES it at the point it was earned,
converting a time-varying gate into a point-in-time one. Detection is unchanged on PRs and
main, which is how DEP-01 and DEP-02 were both found.

Verified live rather than assumed: promoting 1a4f84f fired ONLY `CI` on the production
branch, no Security Checks run. It self-applied on the first promotion because GitHub
evaluates the workflow file at the pushed SHA.

Residual accepted gap (recorded in ADL-40 and security-backlog v1.3): a commit pushed
DIRECTLY to production, bypassing main, would never be scanned. Contained by process only.
