# Brief: OP-11 — Stabilise E2E isolation and wire Playwright into CI

**From:** COO | **To:** QA agent | **Date:** 2026-07-16
**Tracker:** OP-11 | **GitHub:** #119 | **Priority:** P2
**Branch:** `chore/op11-e2e-ci`

## Context

The 36-spec Playwright suite (src/e2e/) is not in CI and rotted silently for 4 months —
PR #118 fixed the owner-env breakage (24 pass/12 fail → 34 pass/2 fail). Root remaining
problem: spec files share one `e2e.db` (workers:1, sequential) and leak state into each
other. `trips.spec.ts` "search filters trips" and "trip detail opens on click" pass in
isolation but fail in the full run.

Related: ADL-22 (E2E infrastructure decision — read it), known detail-panel
`data-testid` scoping debt.

## Requirements

1. **Isolation:** make every spec file state-independent. Options (your call, justify in
   PR): truncate user-data tables in a global/per-file setup via a helper hitting the API
   (a `deleteAllTrips`-style reset exists in `src/e2e/helpers/factories.ts` — but note it
   only clears trips; cities/admin data persist), or unique per-file fixture naming.
   Diagnose the 2 failures first — fix the actual leak, don't just rename fixtures blind.
2. **Selector robustness:** add `data-testid` attributes where specs currently use
   fragile text/class selectors — at minimum the trip detail panel (`trip-detail` is
   already referenced by `trips.spec.ts` with an `.or()` fallback — make it real).
   Frontend markup changes must not alter behaviour; update frontend component tests if
   structure changes.
3. **CI job:** add `E2E Tests` job to `.github/workflows/ci.yml` (follow existing job
   conventions — pinned action SHAs per BUG-24 lesson): checkout, node setup, `npm ci`,
   `npx playwright install --with-deps chromium`, `npm run test:e2e`. Upload
   `playwright-report/` as artifact on failure. Playwright's webServer config starts both
   servers itself (BYPASS_AUTH + OWNER_CLERK_ID already set there by PR #118).

## Success criteria

- 36/36 pass on 3 consecutive full local runs (retries stays 0 — fix flakes at source, per config comment)
- E2E CI job green on the PR; report artifact wiring demonstrably works
- Added CI wall time ≤ ~3 min
