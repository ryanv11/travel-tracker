type="button" calling handleSave directly instead of type="submit" — the

ANY field via Enter, structurally, in any browser. Replaces round 1's
(#458) per-field onKeyDown deny-list, which is exactly the shape of gap
that let the click path through undetected.

missed, since it left required fields empty, masking a real submit behind

container has no sudo password, so playwright install webkit/firefox
