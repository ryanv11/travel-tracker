3. FYI: YOUR CLAUDE MEMORY NOW HAS A NIGHTLY BACKUP (HOST)
Why it exists: your memory lives in the claude-code-config-* Docker volume,
inside Docker's VM disk, and that disk is excluded from Time Machine (it changes
constantly). So a LaunchAgent, com.travel-tracker.memory-backup, runs at 02:30.
It copies projects/*/memory from any claude-code-config-* volume that holds a
-workspace memory (read-only mount, no network) to
~/Backups/travel-tracker-claude-memory/<date>-<volume id>.tgz. It keeps 90
days, prunes only after a good run, and puts up a banner if 3 days pass without
a backup. It needs Docker Desktop running. Its first run (11 Oct) copied 54
files, and the memory on the mini was byte-identical to the Air's export.
Ask: record this wherever you document host setup, so a future rebuild or move
knows the memory is backed up and where. A rebuild that changes the
devcontainerId creates a new volume, which the script picks up automatically.
