Waypoint

Design system

A working palette, type scale and component set for Travel Tracker — proposed name "Waypoint." Restyle proof-of-concept for the Trips screen follows in two companion files.

Color

Warm paper neutrals + a deep pine primary. Status/category accents share the same lightness and chroma, varying only hue — so meaning comes from color, not intensity.

Compare to today's app: teal-600 on most screens, blue-600 in Admin, plus indigo/green/emerald/yellow scattered across statuses with no shared logic.

Type

Newsreader for display — gives the editorial, journal-like warmth the brand wants. Manrope for UI text — stays legible and dense at small sizes.
