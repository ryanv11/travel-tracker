THE BLOCKER (B1) AND ITS FIX
- B1: R1's D8 §3b(3) "cached-first-gate" reintroduced BUG-97. It suppressed the live lookup when
  exactly one exact-name cached row existed, so "Newport" (one cached "Newport, Oregon") showed
  only Oregon; the alternatives were never fetched. A single cached row carries ZERO information
  about whether other real places share the name — no threshold on a cache-only signal is safe.
- FIX (PO Option A, invisible autofire): the live lookup fires on the SETTLED query (debounce 300ms
  + min-2-chars) REGARDLESS of a single exact cached match. Bounded by debounce + min-length +
  per-query session cache (<=1 call per distinct settled name). Staleness-safe (last-query-wins;
  superseded responses discarded; in-flight cancelled). One isolated policy point (rollback seam:
  enabled: auto|manual). Multi-user aggregate budget is the PARKED D-33 thread, NOT designed here.
